# Online Assignment Submission System

A simple front-end mini project for submitting and managing student assignments.

## Technologies
HTML, CSS, JavaScript, Browser Local Storage

## Features
- Student details
- Assignment title and subject
- Due date
- File selection
- Submission confirmation
- Submitted assignment list
- Delete record

## Run
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. Enter assignment details and submit.

Note: This demo stores the selected file name in browser Local Storage; it does not upload the actual file to a server.
